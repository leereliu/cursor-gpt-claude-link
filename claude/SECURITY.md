# Security reports

Do not post credentials, configuration, installation manifests, model caches, patched bundles or backups in public issues. These can contain account data or the local bridge key.

For a sensitive vulnerability, use GitHub's private vulnerability reporting if available on this repository. If it is unavailable, open an issue requesting a private contact method without including exploit details or secrets.

For ordinary bugs, include software versions and a redacted error. The bridge listens on loopback and requires a random local key; do not expose its port to other machines.
